# Portfolio Architecte – Sophie Bluel

## Contexte

Le projet Portfolio Architecte – Sophie Bluel consiste à développer un site web dynamique permettant de présenter les travaux d’une architecte.

Ce projet a été réalisé dans le cadre de la formation Développeur Web chez OpenClassrooms.

L’objectif principal est de transformer une page statique en une application web dynamique capable d’interagir avec une API et de proposer une interface d’administration.

---

## Objectif

- Dynamiser une page HTML existante avec JavaScript
- Récupérer et afficher des données depuis une API REST
- Implémenter un système de filtrage par catégories
- Mettre en place une authentification administrateur
- Permettre l’ajout et la suppression de projets
- Gérer le stockage du token via LocalStorage
- Versionner le projet avec Git & GitHub

---

## Stack technique

- HTML5
- CSS3
- JavaScript (ES6)
- API REST
- Fetch API
- LocalStorage
- Git

---

## Compétences développées

- Manipulation du DOM
- Gestion des requêtes asynchrones
- Traitement de données JSON
- Gestion de l’authentification côté front-end
- Création de modales dynamiques
- Organisation et structuration d’un projet JavaScript

---

## Résultats et impact

- Portfolio dynamique connecté à une API
- Affichage automatique des projets
- Filtrage fonctionnel par catégories
- Interface administrateur opérationnelle
- Ajout et suppression de projets en temps réel
- Validation du projet par OpenClassrooms
